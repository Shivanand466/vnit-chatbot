Programming exercises on Memory Virtualization topics
Objective
: To practically introduce various topics in memory virtualization.
Problem 1:
Verify the process address space by printing addresses for elements from various segments of address space (refer to 3 rd reference). Also experiment with the demo program (3 rd reference) and commands like pmap
, vmstat
, and free to understand various aspects of virtual memory and its management (refer to 4 th reference).

Edit test programs to deliberately introduce various common errors that arise while using memory API and debug those with efence
+ gdb and valgrind debuggers.

Implement a simulator for managing free memory in heap using free list implemented with header block mechanism as discussed in OSTEP Chapter 17. See the details in the assignment document (Reference 2)
