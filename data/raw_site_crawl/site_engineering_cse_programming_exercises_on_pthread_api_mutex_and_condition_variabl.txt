Programming exercises on pthread API, mutex and condition variables
Objective
: To understand the pthread API and the concept of mutex and condition variables, and implement practice problems on these concepts using pthread library (pthread.h).
Problem 1:
Use ‘main’ thread to create 2 new threads as mentioned below.
The first thread should loop N times printing one dot character (.) in each iteration.
The second thread should loop N times printing one pipe character (|) in each iteration.
As the threads will be in competition for access to the screen, the output may have transitions like ‘….||||||…..|||||………||||||||||||||||….’ depending on your system.
This lets you observe the threads getting and using their timeslices on the CPU.
The ‘main’ thread should wait for completion of these two threads.
Now try to change the priority of execution of second thread so that it finishes the printing to a large extent (or completely) before passing the control to next thread. Try different values of N and the priority and observe the change in the output.
Note:
If your system have only a single CPU core (like most online compilers), you may not get the overlap in the pattern. However, you should still be able to run second thread before the first with changed priority value. On a multi-core system though, you should be able to see different patterns which depend on the CPU allocation of threads.
Problem 2:
Write a program using C and pthread library to perform a parallel matrix multiplication routine. The goal is to multiply an MxN matrix (A) by an NxP matrix (B) and then store the result into the MxP matrix (C). You can design your program in such a way that each thread does an equal share of the work or you can have the threads run in a loop that computes single rows of the result (i.e. C). Also print time taken by each thread and compare the time taken by C program with threads (parallel program) and without threads (sequential program). Use gettimeofday() to measure the time.
Note: Again if your system have only a single CPU core (like most online compilers), you may not get much difference in the time taken by parallel program and sequential program. However, on multi-core systems you should see faster execution of parallel program for sufficiently large values of M,N and P.
Problem 3:
Calculate the addition of all the elements in a single array using multiple threads. Use mutex to implement critical section so that no two threads simultaneously update the global result variable (that stores the final addition result).
Problem 4:
Implement the Producer/Consumer problem for managing a buffer represented by a stack. Assume the following:
The buffer is a stack with at most 5 elements. Each element has a random integer value (between 0 to 30). Initially the stack will be empty.
At the start of the program, the producer will push 5 (maximum allowed number of elements) elements to the stack and print a message with its value to the screen. Once the stack is full, producer should print a message and wait.
Consumer will perform pop operation on the stack and print a message with its value to the screen. When the stack is empty, it should print a message and wait.
