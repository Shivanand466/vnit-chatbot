Computer Centre
The Centralized Computing Facility to cater the need of 4000 odd students on campus is taken by the computer centre. The centre remains open for extended hours every day. The students visiting the centre during odd hours are provided guidance as and when necessary. The computer centre has adequate number of PC’s so that UG students, PG students, PhD Scholars can access those for information collection and study.

Frequently Asked Questions – FAQs
Frequently Asked Questions – FAQs 1. How I can access Internet in Computer Centre?
You have to put Proxy Server Address in the Web Browser you are using 2. What are the Proxy Server Addresses which I can use in Computer Centre?
There are total 2 Proxy Server Addresses you can use in Computer Centre.
172.31.16.10 Port no. 8080 172.31.4.6 Port no. 8080 3. How to Change Proxy Server Address in the Web Browser?
Changing Proxy is different from Browser to Browser. It is listed below:-
Internet Explorer:-
Go To –>Tools –>Internet Options –>Connections –>LAN Settings –>Proxy Server
Here you have to enter either 172.31.4.5 or 172.31.4.6 or 172.31.16.10
And Port No. must be: – 8080
Google Chrome:-
Go To –> Customize and Control Google Chrome –>Option –>Under the Hood –>Change Proxy Settings
This will open a window which is similar to IE. Note here, the Proxy you set for your Internet Explorer is automatically applied to Google Chrome and Vice Versa.
For images related to changing proxy in Google Chrome Click Here
Mozilla Firefox: –
Go To –> Tools –> Options –> Advanced –> Network –> Settings –> Manual Proxy Configuration
Here you have to enter either 172.31.4.5 or 172.31.4.6 or 172.31.16.10
And Port No. must be: – 8080
For images related to changing proxy in Mozilla Firefox Click Here 4. How to access various International Journals / Papers which our VNIT Library has Subscription?
If you know the link of the International Journals / Papers you want, you can access it through any Web Browser, but make sure you have set your proxy to
“172.31.4.6 & port no. 8080”
. List of all E-Resources available with VNIT’s Library and Information Centre can be found under the link, https://vnit.ac.in/index.php?option=com_content&view=article&id=464&Itemid=190 4. Can I use my personal Laptop to connect to Computer Centre’s network to access Internet?
Officially you don’t have access right to use your personal Laptop or device to connect to Computer Centre’s LAN. But for any project related or official VNIT’s students events work, we are giving access to few devices, but for that students need to give request letter to our Computer Centre In-Charge or He / She can bring recommendation letter from any Professor, Associate Professor or Assistant Professor (Guide or In-Charge of the Event).
5. In which user I can access Internet and other general work?
You have to use Student – Account to access internet, routine practical work and all other general work.
6. How to access NPTEL Videos?
If you want to access NPTEL Videos then you have to follow link below: – https://vnit.ac.in/index.php?option=com_content&view=article&id=165&Itemid=162
